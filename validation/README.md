# Development evidence

Each folder contains actual development inference, not final test results.

- dev_smoke_63: original 63-call CPU check before the implementation update.
- dev_smoke_v3_63: 63 calls during the update, before the export helper and default pilot folder were finalised.
- cpu_smoke_verified_63: 63 calls from the final updated runner; model/checkpoint/prompts/data unchanged.

Do not select the most favourable dev run as a final result or combine these timings as a fair benchmark. Execution source hashes are recorded in each metadata file. Only results/final can supply the final experiment table after a genuine freeze.
