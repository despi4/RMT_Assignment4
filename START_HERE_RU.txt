БЫСТРЫЙ СТАРТ — WINDOWS CPU

1. Новый компьютер: установите Python 3.12 и Git, клонируйте репозиторий.
2. В PowerShell в папке проекта выполните:
   .\experiment.ps1 setup
   .\experiment.ps1 check
   .\experiment.ps1 pilot

Если среда уже установлена, setup пропустите. Укажите RMT_PYTHON и HF_HOME
как в README. Pilot = 63 dev-ответа; это не финальные результаты.

3. Сохраните точный загруженный Appendix A и реальный receipt Moodle.
   В README есть команда freeze с настоящей датой, timezone, именем и путями.
   Техническое обновление после Appendix A описано в docs/IMPLEMENTATION_UPDATE.json.
   Включите его и commit в Deviations from the frozen protocol.
4. После freeze:
   .\experiment.ps1 final
   .\experiment.ps1 analyze

Final = 2520 реальных ответов: 120 фактов, 7 условий, 3 context seeds.
Модель Qwen 0.5B работает на CPU float32, 2 потока. Обучения модели нет.
На экране видны прогресс и примерное оставшееся время. Ctrl+C сохраняет
готовые строки. Та же команда продолжает их при совпадающих коде/данных/среде.

5. results/analysis: таблицы, CI, статистика Holm, 4 SVG графика, error_review.csv.
   Вдвоём разберите 30 ошибок (или все, если меньше), затем review_errors.py.
6. Другой студент повторяет исследование в чистой среде через --phase reproduction.
7. Напишите отдельный report, сравните 3 источника из Assignment 1, оформите A–C.
   После проверки опубликуйте реальные результаты и release assignment-4.

Точные команды, файлы результатов и объяснения — README.md.
Модель и данные не меняются ради улучшения финальных результатов.
